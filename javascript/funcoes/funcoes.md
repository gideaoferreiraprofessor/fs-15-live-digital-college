# Funções

São blocos de código que podem ser reutilizados em diferentes partes de um programa.
Elas permitem organizar o código, tornando-o mais legível e fácil de manter.

### Estrutura básica de uma função

- Declaração de função: function
- Nome da função: deve ser um identificador válido.
- Parâmetros: valores que podem ser passados para a função.
- Scopo: o contexto em que a função é definida e onde ela pode acessar variáveis.

```javascript
// Básica declaração de uma função
function nomeDaFuncao() {
  // Bloco de código
}
```
