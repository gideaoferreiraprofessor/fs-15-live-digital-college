# DOM

O DOM significa Document Object Model, ou Modelo de Objeto de Documento.
Ele é uma interface de programação para documentos HTML e XML.
Ele representa a página para que programas possam alterar a estrutura do documento,
estilo e conteúdo.

```javascript
// Exemplo de como acessar o DOM - Ele retorna o objeto document,
// que representa o documento HTML carregado no navegador.
document;
```
