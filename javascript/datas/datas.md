# Trabalhando com Datas(date) em JavaScript

A classe `Date` do JavaScript é usada para trabalhar com datas e horas.
Ela permite criar, manipular e formatar datas de diversas maneiras.
A seguir, apresento alguns exemplos de como utilizar a classe `Date` em JavaScript.

### Criando uma nova data

```javascript
// Criando uma nova data com a data e hora atuais
const dataAtual = new Date();

// Criando uma nova data com um valor específico
const dataEspecifica = new Date("2023-10-15");
```
