# O que é um objeto?

Um objeto é uma coleção de propriedades, onde cada propriedade é uma associação entre uma chave (ou nome) e um valor.
Em JavaScript, objetos são usados para armazenar dados complexos e podem conter outros objetos, arrays, funções e valores primitivos.

```javascript
// Criando um objeto simples
const pessoa = {
  nome: "João",
  idade: 30,
  profissao: "Desenvolvedor",
  genero: "Masculino",
  email: "joaopedefeijao@gmail.com",
};
```
