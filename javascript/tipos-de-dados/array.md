# Array

Um array em JavaScript é uma estrutura de dados que permite armazenar
múltiplos valores em uma única variável. Cada valor no array é identificado
por um índice, que começa em 0.

```javascript
let frutas = ["maçã", "banana", "laranja"];
let textos = [
  "Olá, como você está?",
  "Bem-vindo ao JavaScript!",
  "Aprendendo sobre arrays.",
];
let multiplosTipos = [42, "texto", true];
// Resultado:
// [
//   0: 42,
//   1: "texto",
//   2: true
// ]
multiplosTipos[0]; // 42
multiplosTipos[1]; // "texto"
let numeros = [1, 2, 3, 4, 5];
```
