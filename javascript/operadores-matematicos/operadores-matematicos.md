# Operadores matemáticos

Os operadores matemáticos são utilizados para realizar operações aritméticas em valores numéricos.

# Soma

O operador de soma é representado pelo símbolo `+` e é utilizado para somar dois ou mais valores.

```javascript
let a = 5;
let b = 10;
let resultado = a + b; // resultado será 15
5 + 6; // resultado será 11
```

# Subtração

O operador de subtração é representado pelo símbolo `-` e é utilizado para sub
trair um valor de outro.

```javascript
let a = 10;
let b = 5;
let resultado = a - b; // resultado será 5
```

# Multiplicação

O operador de multiplicação é representado pelo símbolo `*` e é utilizado para multiplicar dois ou mais valores.

```javascript
let a = 5;
let b = 10;
let resultado = a * b; // resultado será 50
```

# Divisão

O operador de divisão é representado pelo símbolo `/` e é utilizado para dividir um valor por outro.

```javascript
let a = 10;
let b = 2;
let resultado = a / b; // resultado será 5
```

# Resto da Divisão

O operador de resto da divisão é representado pelo símbolo `%` e é utilizado para
obter o resto da divisão de um valor por outro.

```javascript
let a = 10;
let b = 3;
let resultado = a % b; // resultado será 1

10 % 2; // resultado será 0
```
