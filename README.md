# fs-15-live-digital-college
Repositório criado para a turma de Fullstack Javascript da Digiral College. Exemplos, Exercícios e material de apoio.

O backend da loja mantém 10 produtos originais e inclui 100 produtos novos, selecionados de 68 subcategorias do catálogo de imagens. Os produtos têm descrições com pelo menos 500 caracteres e imagens locais em `backend/assets/uploads/products-images`.
