# ReactJS

É uma biblioteca JavaScript de código aberto para criar interfaces de usuário.
É mantida pelo Facebook e por uma comunidade de desenvolvedores individuais
e empresas. React pode ser usado como base no desenvolvimento de aplicativos de
página única ou móveis.

### Comando para criar projeto React

```bash
npm create vite@latest
```

#### Seguir o wizard de criação do projeto, selecionando as opções desejadas.

- Escolher o nome do projeto.
- Selecionar o framework: React.
- Selecionar a linguagem/variaçào(variation): JavaScript.
- Selecionar o ESLint: Yes.
- Selecionar o gerenciador de pacotes: npm.
- Entrar na pasta do projeto: `cd nome-do-projeto`.
- Instalar as dependências: `npm install`.
- Executar o projeto: `npm run dev`.
